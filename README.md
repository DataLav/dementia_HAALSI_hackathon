# dementia_HAALSI_hackathon
R and Python code from the Boston University Hackathon epidemiological data analysis on Dementia and Healthy Aging. The Dataset has to be accessed from the Harvard Dataverse website; it is not provided herein. 
References:
rd Center for Population and Development Studies (Harvard T.H. Chan School of Public Health), C. (2023). HAALSI Wave 3 Survey (Version V2) [Data set]. Harvard Dataverse. https://doi.org/10.7910/DVN/Q2JFPV
